Change Summary

New Components
QuickCreatePopover
Small, focused component. Name input, three buttons, popover positioning, click-outside handling.
Modified Components
CategoryManagerModal
New view state, slide container, removed side-by-side layout, updated close behavior.

CategoryManagerTree
Row click triggers edit (not select). No active state styling.

CategoryManagerForm
Added back link, footer integrated, accepts initialName prop.
Unchanged
categoryManagerTreeUtils.ts
Tree building, flattening, reorder logic — all stays the same.

CategoryTemplateSelector
Used inside form, no changes.

All confirmation modals
Delete, discard, publish, unpublish, slug setup.

CSS Changes

CategoryManagerModal.css — primary changes:

• .categoryManager — changes from flex row to overflow:hidden viewport
• .categoryManager__track — new sliding track (width:200%, flex row, transition)
• .categoryManager__tree — changes from fixed 280px to 50% width
• .categoryManager__form — changes from flex:1 to 50% width
• .categoryManager__footer — moves inside form panel (conditional render)
• New: .quickCreatePopover styles (positioning, shadow, backdrop)
• Remove: .catTree__row--active (no selection state in tree)
