Key Implementation Details

View State

Single state variable: 'tree' | 'form'

Controls the translateX value via a CSS class toggle

Animation

CSS transition: transform 300ms ease-in-out

Smooth, GPU-accelerated slide

Footer Behavior

Footer (Delete/Cancel/Save) only visible when view === 'form'

Tree view has no footer buttons

Modal Close (×)

Tree view: closes immediately

Form view w/ changes: confirm discard → return to tree
