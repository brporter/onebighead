Auto-Select Parent

When you drill into a category, "All [Category]" is automatically selected, showing all items in that category and its descendants. Clicking a subcategory drills deeper. This means drilling in = selecting + viewing children. One action, two results.

Separate Drill & Select

Drilling into a category only changes the sidebar view — it doesn't select anything yet. You then click a specific subcategory (or "All") to load its items. The chevron (›) on leaf-less subcategories drills deeper; the row itself selects. This separates navigation from selection but adds an extra click.

Also note: Both options show the edit icon (✎) on hover for each category row. The chevron (›) only appears on categories that have children — it indicates "drill deeper." Leaf categories have no chevron; clicking them always selects.
