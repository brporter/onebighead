A: Fraunces + DM Sans

Fraunces is a variable serif with old-style character — slightly quirky, warm, and full of personality. Pairs with the clean geometry of DM Sans. The contrast is strong: item names feel like museum nameplates, body text stays crisp and functional.

B: Lora + Inter

Lora is a more traditional, balanced serif — refined and readable. With Inter for body text, the result is polished and professional. Less personality than Fraunces, but more universally elegant. Classic museum typography.

What to look at: Notice how the item names (Leica M3, Rolleiflex 2.8F) feel like nameplates in each pairing. The display font carries the personality while the sans-serif keeps UI elements clean and scannable. Both pairings work with the Living Gallery palette.
